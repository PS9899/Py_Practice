# Python Practice Repository

A comprehensive Python learning repository containing exercises, notebooks, and practical examples for mastering Python programming from basics to data science.

## 📚 Contents

### Core Resources
- **Python Data Science Handbook** - Jupyter notebooks covering:
  - IPython: Beyond Normal Python
  - NumPy: Data manipulation and numerical computing
  - Pandas: Data analysis and manipulation
  - Matplotlib: Data visualization
  - Advanced topics and applications

- **Python Cheat Sheet** - Quick reference for common Python patterns and syntax

- **101 Exercises** - Practical exercises for hands-on learning

## 🚀 Getting Started

### Prerequisites
- Python 3.7+
- Jupyter Notebook or JupyterLab
- Required packages (see requirements.txt)

### Installation

1. Clone the repository:
```bash
git clone https://github.com/PS9899/Py_Practice.git
cd Py_Practice
```

2. Create a virtual environment:
```bash
python -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate
```

3. Install dependencies:
```bash
pip install -r requirements.txt
```

4. Launch Jupyter:
```bash
jupyter notebook
```

## 📖 How to Use

1. **Start with Basics**: Begin with the IPython notebooks to get familiar with the environment
2. **Learn Core Concepts**: Work through NumPy, Pandas, and Matplotlib notebooks sequentially
3. **Practice**: Solve exercises from the 101-exercises notebook
4. **Reference**: Use the Python cheat sheet as a quick reference guide
